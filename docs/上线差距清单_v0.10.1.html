🛣️ 推荐上线路线 三步走

第 1 步 · 内部试运行（1-2 周）

先把 5 项代码 P0 全部补完（打字速度是用户最初诉求，必须做）。

找 1-2 个客服当小白鼠，跑自由训练 + 1 套批次题，看主流程是否跑通。

完成标志：客服能登录、能聊天、有分数、能看回放。

第 2 步 · 题库 + 资料 补料（2-3 周）

你把 聊天资料 + 题库 + 评分规则 给到我。

我把题库批量导入 + 让 AI 客户"学你们家说话"。

完成标志：客服训练完觉得自己真见过这客户。

第 3 步 · 灰度上线（持续）

3-5 个客服先用，每周根据反馈调整（批次题难度、评分校准、快捷短语）。

同时上 HTTPS + 进程守护 + 自动备份。

完成标志：新人入职 SOP 里加"过 kefuxitong 训练 80 分才上号"。

🚀 你现在立刻能给我的（加速用）

如果你想让我马上接着推，下面任一材料都给得到位：

  1. 20 条聊天记录（txt 转写即可，脱敏后的），我立刻做"训练语料迁移"，让 AI 客户演得更像
  2. DeepSeek API Key 或已有余额账号 → 写到 backend/.env → 我配好 LLM 异常兜底

  4. 客服登录浏览器型号 → 我针对性测移动端
  5. 外部域名（如有） → 我规划 HTTPS / 反代方案
